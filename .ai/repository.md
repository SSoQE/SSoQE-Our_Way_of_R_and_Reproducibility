# Repository-specific guidance

This template-derived lecture repository is the active base for Our Way of R and Reproducibility.

- Active lesson sources remain under `Presentation/` and `R/Exercises/`; render the active presentation through `Rscript R/render.R`.
- `Source_material/SSoQE-Reproducibility_in_Science/` is an immutable editorial-review bundle. Verify it against `Source_material/SHA256SUMS`; do not render, edit, move, delete, or publish files from that directory as active lesson content.
- The separate-project `sprout_logo` is intentionally absent from the imported bundle and is not SSoQE branding.
- Editorial consolidation of the imported material into the active lesson requires a separate reviewable content change.
